## 一、ST7789 显示屏 (SPI)

| 显示屏引脚 | ESP32-S3 引脚 | 说明 |
|-----------|-------------|------|
| VCC | 3.3V | 电源 3.3V |
| GND | GND | 共地 |
| SCL / SCLK | GPIO 14 | SPI 时钟 |
| SDA / MOSI | GPIO 13 | SPI 数据 |
| CS | GPIO 15 | 片选 |
| DC | GPIO 16 | 数据/命令选择 |
| RST | GPIO 17 | 复位 |
| BL / LED | GPIO 18 | 背光控制（PWM 调光） |

```
ESP32-S3                          ST7789 显示屏
┌──────────┐                      ┌──────────────┐
│   3.3V   ├──────────────────────┤ VCC          │
│   GND    ├──────────────────────┤ GND          │
│ GPIO 13  ├──────────────────────┤ SDA / MOSI   │
│ GPIO 14  ├──────────────────────┤ SCL / SCLK   │
│ GPIO 15  ├──────────────────────┤ CS           │
│ GPIO 16  ├──────────────────────┤ DC           │
│ GPIO 17  ├──────────────────────┤ RST          │
│ GPIO 18  ├──────────────────────┤ BL / LED     │
└──────────┘                      └──────────────┘
```

> 注意：部分 ST7789 模块将 BL 直连到 3.3V（不可调光），此时 GPIO 18 可不接。部分模块无 RST 引脚，可省略 GPIO 17。

## 二、INMP441 麦克风 ×2 (I2S)

使用 **单 I2S 总线 + 左右声道分离** 方式连接两颗麦克风。

| 麦克风引脚 | ESP32-S3 引脚 | 说明 |
|-----------|-------------|------|
| VDD | 3.3V | 电源 3.3V |
| GND | GND | 共地 |
| SCK | GPIO 4 | I2S 位时钟（两颗共用） |
| WS | GPIO 5 | I2S 字选/左右时钟（两颗共用） |
| SD (左) | GPIO 6 | 左声道数据输入 |
| SD (右) | GPIO 7 | 右声道数据输入 |
| L/R (左) | GND | 左声道: 拉低 |
| L/R (右) | 3.3V | 右声道: 拉高 |

```
ESP32-S3              左 INMP441                  右 INMP441
┌──────────┐          ┌──────────┐               ┌──────────┐
│   3.3V   ├──────────┤ VDD      │         ┌─────┤ VDD      │
│   GND    ├──┬───────┤ GND      │         ├─────┤ GND      │
│          │  │  ┌────┤ L/R(GND) │         │  ┌──┤ L/R(3.3V)│
│ GPIO 4   ├──┼──┼────┤ SCK      │         ├──┼──┤ SCK      │
│ GPIO 5   ├──┼──┼────┤ WS       │         ├──┼──┤ WS       │
│ GPIO 6   ├──┼──┼────┤ SD       │         │  │  │          │
│ GPIO 7   ├──┼──┼──────────────────────────┼──┼──┤ SD       │
└──────────┘  │  │                          │  │  └──────────┘
              │  │  ┌───────────────────────┘  │
              │  └──┤ 左 L/R 接 GND = 左声道   │
              └─────┤ 右 L/R 接 3.3V = 右声道  │
                    └──────────────────────────┘
```

> 两颗麦克风的 SCK 和 WS 并联到同一 GPIO。左麦克风 L/R 引脚接地（左声道），右麦克风 L/R 引脚接 3.3V（右声道）。
> 麦克风应安装在球体左右两侧，间距 10-15cm。

## 三、TMC2209 步进电机驱动

| TMC2209 引脚 | ESP32-S3 引脚 | 说明 |
|-------------|-------------|------|
| VIO | 3.3V | 逻辑电源 |
| GND | GND | 共地 |
| VM | 5V~12V 外接电源 | 电机电源（根据电机规格） |
| STEP | GPIO 10 | 步进脉冲 |
| DIR | GPIO 11 | 方向控制 |
| EN | GPIO 12 | 使能（低有效） |

```
ESP32-S3                      TMC2209                  步进电机
┌──────────┐                ┌──────────┐              ┌──────────┐
│   3.3V   ├────────────────┤ VIO      │              │          │
│   GND    ├────────────────┤ GND      │              │          │
│ GPIO 10  ├────────────────┤ STEP     │              │          │
│ GPIO 11  ├────────────────┤ DIR      │              │          │
│ GPIO 12  ├────────────────┤ EN       │              │          │
│          │                │          │              │          │
│   (外接) │                │ VM  ←─── 外部电源正极   │          │
│   (外接) │                │ GND ←─── 外部电源负极   │          │
│          │                │          │              │          │
│          │                │ 2B  ────────────────────┤ A- (线圈1)│
│          │                │ 2A  ────────────────────┤ A+ (线圈1)│
│          │                │ 1A  ────────────────────┤ B+ (线圈2)│
│          │                │ 1B  ────────────────────┤ B- (线圈2)│
└──────────┘                └──────────┘              └──────────┘
```

> TMC2209 的 EN 引脚内部上拉——不接时电机默认关闭，接 GPIO 12 由程序控制。

## 四、UART1 串口通讯（状态输出）

| 用途 | ESP32-S3 引脚 | 说明 |
|------|-------------|------|
| TX | GPIO 8 | 状态数据发送 |
| RX | GPIO 9 | 指令接收（可选） |

```
ESP32-S3                      USB-UART 模块 (TTL)
┌──────────┐                  ┌──────────────┐
│ GPIO 8   ├──────────────────┤ RX           │──→ 电脑 USB 串口工具
│ GPIO 9   ├──────────────────┤ TX           │
│ GND      ├──────────────────┤ GND          │
└──────────┘                  └──────────────┘
```

> UART0（GPIO 43/44）通过开发板内置 USB 口输出系统日志。
> UART1（GPIO 8/9）独立输出机器人状态数据，需要外接一个 USB-TTL 模块。
> 波特率默认 115200，数据格式：`RBT:<状态>,<角度>,<检测到声音>,<运行时间>`

## 完整接线速查表

| GPIO | 功能 | 连接到 |
|------|------|--------|
| 4 | I2S BCK | 两个 INMP441 SCK（并联） |
| 5 | I2S WS | 两个 INMP441 WS（并联） |
| 6 | I2S DIN | 左 INMP441 SD |
| 7 | I2S DIN | 右 INMP441 SD |
| 8 | UART1 TX | USB-TTL 模块 RX |
| 9 | UART1 RX | USB-TTL 模块 TX |
| 10 | STEP | TMC2209 STEP |
| 11 | DIR | TMC2209 DIR |
| 12 | EN | TMC2209 EN |
| 13 | SPI MOSI | ST7789 SDA |
| 14 | SPI SCLK | ST7789 SCL |
| 15 | SPI CS | ST7789 CS |
| 16 | SPI DC | ST7789 DC |
| 17 | SPI RST | ST7789 RST |
| 18 | SPI BL | ST7789 BL/LED |
| 43 | UART0 TX | 内置 USB-UART（日志输出） |
| 44 | UART0 RX | 内置 USB-UART |

> 供电说明：ESP32-S3-DevKitC 通过 USB 供电（5V）。电机需要独立供电（根据电机额定电压，通常 5V~12V），**电机电源不可从开发板 5V 引脚取电**（电流过大）。INMP441 和 ST7789 从开发板 3.3V 取电。所有模块的 GND 必须共地。
